# 代码规范
## 使用场景
dev-engineer 编码、修改、重构代码自动加载。

## 通用要求
1. 外部输入必须校验；不要信任前端、API 参数。
2. 错误捕获：区分业务错误、系统异常；带上错误码，不要裸抛异常。
3. 密钥、配置、环境变量不硬编码；使用配置/环境注入。
4. 函数短小，单一职责；新增接口补全注释、参数说明。
5. 新增功能配套最小自测代码；优先复用已有测试骨架。
6. 修改遗留代码：最小侵入；如果重构范围大，先写测试再重构。

## 提交变更原则
- 一次提交聚焦一个意图；大模块拆成多个任务卡片。
- 改动后保证项目可启动、原有测试不大面积崩掉。
