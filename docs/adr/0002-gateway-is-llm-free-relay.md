# 网关为纯中转服务，自身不含 LLM

产品中的"独立 agent"（网关）决定实现为**无模型的确定性服务**：校验登录令牌与任务状态、做命令格式/白名单/频控校验、在前端 WebSocket 与 dsh-webapi REST/SSE 之间转换协议，仅此而已。智能全部留在 DSH 侧。

## Considered Options

- **纯中转网关（选定）**：零模型成本、零推理延迟，攻击面是普通 web 服务；"验证命令有效"用确定性规则即可覆盖（令牌有效、状态机允许、消息大小、频控）。
- **网关自带 LLM 判断命令有效性**：为校验再引入一个模型，增加成本、延迟与新的失败模式，而 DSH 本身就会拒绝无效任务。

## Consequences

- 代码中不应出现任何 LLM 客户端；若未来需要"智能"预过滤，应先在此 ADR 记录再改动。
- 网关的校验规则是规则引擎而非模型 prompt，行为可预测、可单元测试。
