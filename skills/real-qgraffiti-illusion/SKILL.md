# 技能说明
## 技能用途
基于参考图身份锁定生图，生成【真人+同人物巨型Q版涂鸦壁画互动错觉】3:4竖版超写实人像，严格锁定参考图人脸特征，控制构图、服饰、卡通形象、涂鸦元素、光影参数，适配trae dsh绘图模型。

## 核心约束（强制优先）
1. 必须以上传参考照片作为人物身份参照，**严格保留真人全部面部特征：脸型、眼睛、鼻子、嘴唇、肤色、面部比例、独有五官特征，禁止换脸、改脸、重绘面部**
2. 画面比例固定：3:4 竖版
3. 画面核心创意：真实人像摄影 + 墙面巨型Q版卡通分身涂鸦错觉，真人与卡通分身隔空比爱心互动
4. 禁止广角畸变；标语、涂鸦装饰不可遮挡人脸、手部爱心互动区域、人物身体轮廓
5. 分层逻辑固定：前景=真人女性，中景=混凝土涂鸦墙，背景=墙面纹理与街头涂鸦细节

## 调用参数说明
- 画幅比例：3:4
- 参考图权重：建议0.6~0.75（保证人脸锁定，同时允许背景涂鸦自由生成）
- 风格权重：写实优先，不要二次元全局画风，仅墙面壁画部分为Q版卡通涂鸦
- 重点注意：参考图必须上传，不传入参考图会丢失人脸锁定效果

## 使用指引
1. 上传目标人物参考图
2. 正向提示词全量粘贴
3. 粘贴反向提示词到负向框
4. 设置比例3:4，50mm人像参数，参考权重按需微调
5. 生成后校验要点：人脸是否和参考图一致、双爱心互动构图、标语是否齐全、涂鸦元素是否齐全、没有遮挡主体
