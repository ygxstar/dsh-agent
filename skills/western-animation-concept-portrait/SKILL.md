# western-animation-concept-portrait
## Description
接收一张人物参考图，执行图生图，把参考人物重设计为现代西方动画概念原画半身像；只提取人物身份特征，不直接复刻照片脸部、摄影质感。固定构图、笔触风格、色彩规则、底部几何色面设计，输出海报感原画。
## When to use
用户上传一张人物参考图，并且要求：西方动画概念半身像、3渲2手绘原画、参考图重构角色、带底部几何色面、米白留白。用户说出触发口令时启用本技能。
## Input Requirements
必须输入：**人物参考图片**
可选参数：
- image_weight：参考图权重，默认 0.45（推荐区间0.4~0.5）
- size：画布，默认 1280×1024
## Instructions
1. 前置校验：检查对话是否携带参考图；**无参考图时拒绝执行，回复：请上传人物参考图后再调用【western-animation-concept-portrait】技能出图**
2. 拿到参考图后，调用图生图工具，填入下面【正向提示词】、【反向提示词】，并设置参考图权重默认0.45
3. 不擅自修改、精简、改写内置提示词，原样传入绘图模型
4. 出图完成后告知用户：已调用 western-animation-concept-portrait，参考权重0.45，遵循西方动画原画重构规则

### 正向提示词
以这张参考图为人物特征基础，创作高度风格化的西方动画概念艺术人物半身像。参考图仅用于识别人物，不复制真实脸部结构与摄影效果。保留发型、脸型特征、表情、年龄感、肤色、服装与整体气质，但对五官和脸部结构进行明显角色化重构，使其像专业原画师重新设计的动画角色，而非照片转绘。

采用居中但偏小比例构图，胸口以上，人物进一步缩小，四周保留充足米白留白。人物位于视觉中心前景，头部与肩部完整清晰，不占满画面。整体采用强烈的手绘3渲2动画概念艺术风格，弱化摄影感、真实3D体积感和光滑CG感。使用粗粝、厚重、有方向性的干湿笔触，通过涂抹、拖拽、覆盖、擦除、重绘与半透明叠色塑造人物。皮肤、头发和服装使用概括性色面表现，不刻画毛孔、单根发丝和真实材质。

五官进行明显卡通化重构：弱化真实解剖比例，眼睛、眉毛、鼻子和嘴巴采用简化、几何化、概括性的动画设计，适度夸张眼睛与嘴部比例，弱化鼻梁、鼻翼等真实结构。脸部更加简洁、圆润并带有轻微不对称和手绘变形感，同时保留人物辨识度、成人骨骼感和年龄感。卡通化应来自五官与脸部结构本身，避免Q版、幼态脸、日系萌系或搞怪风格。人物轮廓保持速写般的不完整边缘，带有半干擦、飞白、断续、擦淡和局部消散；部分轮廓被笔触覆盖，末端以快速侧锋形成斜切收尾，避免光滑连续描边。

彩色涂抹融入人物色面与光影，使用少量明亮、高纯度但非荧光的亮橙、珊瑚红、明黄、亮蓝、青绿、紫色，以2–3种亮色建立统一关系。彩色笔触自然进入脸部、头发、服装和轮廓，鲜明但保持干净。

背景严格为纯米白色纯色背景，无环境、纹理、图案、渐变或复杂装饰。

人物下方设置大型手绘几何色面，尽量覆盖脖子以下区域，使肩部、下半身和服装自然融入色面。色面明显大于人物主体，作为主要平面设计结构。几何色面主色优先提取人物发色；若戴帽子，则提取帽子颜色。围绕该颜色建立单一主色体系，与头发形成明确呼应。色面使用单一纯色，不使用渐变或多色拼接。

色面以矩形为基础，但边缘带有自然手绘变形、刷痕、拖拽、擦除和颜料覆盖感，保持清晰几何构成，同时避免机械、完美的矢量矩形。光影采用中等明暗对比与电影感色彩，以柔和、有层次的大色面概括结构，避免纯黑阴影、过曝高光和强烈黑白反差。

整体呈现：小比例人物、充足米白留白、大面积发色几何色面、色面覆盖脖子以下区域、人物前景穿插、成人卡通化五官、3渲2手绘原画、粗粝笔触、明亮彩色涂抹、现代西方动画概念艺术、现代平面设计、专业海报感。
